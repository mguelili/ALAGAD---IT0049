# Tasks for Today Management System

A CodeIgniter 4 task-management system created for IT0049 Web System Technologies.

## Features

- Welcome page showing today's tasks
- Complete task list
- User profile page
- About page
- MySQL database connection
- Task filtering by date

## Routes

- `/` - Welcome page
- `/tasks` - Complete Task List
- `/profile` - User Profile
- `/about` - About page

## Local Setup

1. Start Apache and MySQL in XAMPP.
2. Create a database named `tasks_today_db`.
3. Import `tasks_today.sql` in phpMyAdmin.
4. Copy `.env.example` to `.env`.
5. Update the database settings.
6. Run the CodeIgniter development server.
7. Open `http://localhost:8080`.
